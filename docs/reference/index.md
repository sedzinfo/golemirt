## Models

Response functions of the models in the Models menu

- [`prob_4pl()`](https://sedzinfo.github.io/irtexplorer/reference/prob_4pl.md)
  : Four-parameter logistic item response function
- [`prob_gpcm()`](https://sedzinfo.github.io/irtexplorer/reference/prob_gpcm.md)
  : Category response curves of the generalized partial credit model
- [`prob_grsm()`](https://sedzinfo.github.io/irtexplorer/reference/prob_grsm.md)
  : Category response curves of the generalized rating scale model
- [`prob_grm()`](https://sedzinfo.github.io/irtexplorer/reference/prob_grm.md)
  : Category response curves of the graded response model
- [`prob_nrm()`](https://sedzinfo.github.io/irtexplorer/reference/prob_nrm.md)
  : Category response curves of the nominal response model
- [`prob_tirt()`](https://sedzinfo.github.io/irtexplorer/reference/prob_tirt.md)
  [`prob_tirt_pair()`](https://sedzinfo.github.io/irtexplorer/reference/prob_tirt.md)
  [`prob_tirt_intercept()`](https://sedzinfo.github.io/irtexplorer/reference/prob_tirt.md)
  : Probit response functions of Thurstonian IRT
- [`prob_mirt()`](https://sedzinfo.github.io/irtexplorer/reference/prob_mirt.md)
  : Response surface of a two-dimensional dichotomous item
- [`info_mirt()`](https://sedzinfo.github.io/irtexplorer/reference/info_mirt.md)
  : Information surface of a two-dimensional dichotomous item
- [`item_vector()`](https://sedzinfo.github.io/irtexplorer/reference/item_vector.md)
  : Item vector of a compensatory two-dimensional item

## Estimation

The estimation methods of the Estimation menu

- [`response_pattern()`](https://sedzinfo.github.io/irtexplorer/reference/response_pattern.md)
  : Response pattern of a raw score
- [`simulate_responses()`](https://sedzinfo.github.io/irtexplorer/reference/simulate_responses.md)
  : Simulate dichotomous responses
- [`loglik_surface()`](https://sedzinfo.github.io/irtexplorer/reference/loglik_surface.md)
  : Log-likelihood surface of an item's discrimination and difficulty
- [`surface_maximum()`](https://sedzinfo.github.io/irtexplorer/reference/surface_maximum.md)
  : Highest point of a log-likelihood surface
- [`loglik_rasch()`](https://sedzinfo.github.io/irtexplorer/reference/loglik_rasch.md)
  : Log-likelihood of a response pattern under the Rasch model
- [`newton_raphson_rasch()`](https://sedzinfo.github.io/irtexplorer/reference/newton_raphson_rasch.md)
  : Newton-Raphson steps towards the maximum likelihood estimate of
  ability
- [`prior_weights()`](https://sedzinfo.github.io/irtexplorer/reference/prior_weights.md)
  : Prior weights at quadrature points
- [`eap_map()`](https://sedzinfo.github.io/irtexplorer/reference/eap_map.md)
  : EAP and MAP estimates of ability by quadrature

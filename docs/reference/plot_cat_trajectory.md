# Plot the course of a CAT session

An interactive `plotly` chart in two panels side by side: the
standardized ability estimate and its standard error after each answer,
across the whole test, one colour per scale. Hovering a point shows the
statement and the answer; a dashed line marks the standard error at
which a scale stops.

## Usage

``` r
plot_cat_trajectory(s)
```

## Arguments

- s:

  A CAT session with at least one answer (see
  [`cat_start`](https://sedzinfo.github.io/golemirt/reference/cat_start.md)).

## Value

A `plotly` htmlwidget.

## See also

Other CAT session:
[`cat_answer()`](https://sedzinfo.github.io/golemirt/reference/cat_answer.md),
[`cat_item()`](https://sedzinfo.github.io/golemirt/reference/cat_item.md),
[`cat_results()`](https://sedzinfo.github.io/golemirt/reference/cat_results.md),
[`cat_start()`](https://sedzinfo.github.io/golemirt/reference/cat_start.md)

## Examples

``` r
q <- read_questionnaire(example_questionnaires()[3])
s <- cat_start(q, scales = c("Openness", "Extraversion"), se_threshold = 0.5)
while (s$stage == "testing") s <- cat_answer(s, sample(1:5, 1))
plot_cat_trajectory(s)
```

# Plot the parts of an EAP and MAP estimation

Draw the parts of an estimation from
[`eap_map()`](https://sedzinfo.github.io/golemirt/reference/eap_map.md):

- `plot_prior()`:

  the prior weights at the quadrature points;

- `plot_tracelines()`:

  the probability of each observed response across ability, blue for
  items answered correctly and red for items answered incorrectly;

- `plot_likelihood()`:

  the likelihood, the product of those probabilities;

- `plot_posterior()`:

  the posterior, with lines and values for the EAP (blue) and the MAP
  (red);

- `plot_eap_combined()`:

  the prior (red), likelihood (blue) and posterior (black, rescaled to
  be comparable) in one plot, with dashed lines at the prior mean and
  the posterior mean.

## Usage

``` r
plot_prior(estimate)

plot_tracelines(estimate)

plot_likelihood(estimate)

plot_posterior(estimate)

plot_eap_combined(estimate)
```

## Arguments

- estimate:

  Result of
  [`eap_map()`](https://sedzinfo.github.io/golemirt/reference/eap_map.md).

## Value

A `plotly` object.

## Examples

estimate <- eap_map(response_pattern(2))
plot_prior(estimate)

# NRM module - UI

Controls for the scaling constant and the discriminations and
difficulties of the four categories after the reference category of an
item with five unordered categories, and its category response curves.

## Usage

``` r
mod_nrm_ui(id)
```

## Arguments

- id:

  Character. Module namespace id.

## Value

A `tagList` of Shiny UI elements.

## Examples

``` r
if (FALSE) { # \dontrun{
shiny::fluidPage(mod_nrm_ui("nrm"))
} # }
```

# RSM-GRSM module - UI

Controls for the scaling constant, the discrimination, the difficulty
and the four thresholds of an item with five ordered categories, and its
category response curves.

## Usage

``` r
mod_grsm_ui(id)
```

## Arguments

- id:

  Character. Module namespace id.

## Value

A `tagList` of Shiny UI elements.

## Examples

``` r
if (FALSE) { # \dontrun{
shiny::fluidPage(mod_grsm_ui("grsm"))
} # }
```

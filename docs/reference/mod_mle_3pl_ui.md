# MLE 3PL module - UI

Controls for the true lower asymptote, discrimination and location of an
item, and the log-likelihood surfaces for twelve assumed lower
asymptotes.

## Usage

``` r
mod_mle_3pl_ui(id)
```

## Arguments

- id:

  Character. Module namespace id.

## Value

A `tagList` of Shiny UI elements.

## Examples

``` r
if (FALSE) { # \dontrun{
shiny::fluidPage(mod_mle_3pl_ui("mle_3pl"))
} # }
```
